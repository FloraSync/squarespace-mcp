## [0.1.0] - 2026-07-26

- Rebuilt the server against Squarespace's current Commerce OpenAPI schema.
- Added 52 official Squarespace operations covering contacts, analytics, discounts, products, inventory, orders, transactions, profiles, site metadata, and webhooks.
- Added local stdio and remote Streamable HTTP transports.
- Added OAuth 2.1 discovery, Dynamic Client Registration, PKCE, encrypted credential tokens, and a credential onboarding screen for Gemini Spark.
- Added read-only-by-default enforcement, request validation, CI, coverage, npm provenance publishing, Docker packaging, and MCP Registry metadata.
